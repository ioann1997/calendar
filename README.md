# 🦉 Совиная напоминалка

Веб-приложение для отслеживания ежедневных ритуалов, задач от Хозяина и еженедельных ритуалов с системой напоминаний и синхронизацией через Firebase.

## ✨ Функции

- **Ежедневные ритуалы** - отслеживание ежедневных задач с возможностью установки времени напоминания
- **Задачи от Хозяина** - специальный раздел для важных задач
- **Еженедельные ритуалы** - задачи, которые повторяются каждую неделю в определенный день
- **Правила** - список правил
- **Запреты** - список запретов
- **Напоминания** - уведомления в браузере в установленное время
- **🔥 Синхронизация через Firebase** - все данные хранятся в облаке и синхронизируются между устройствами в реальном времени
- **📱 PWA (Progressive Web App)** - можно установить на телефон как приложение
- **🔔 Push-уведомления** - уведомления даже когда приложение закрыто (требует настройки Cloud Functions)
- **Локальный кэш** - данные также сохраняются локально для работы оффлайн
- **Календарь** - визуализация задач в календаре (вид: день/неделя)

## 🚀 Быстрый старт

### 1. Открой приложение

Просто открой `index.html` в браузере или загрузи на GitHub Pages.

### 2. Первый запуск

При первом запуске автоматически создается уникальный `calendarId`. Сохрани ссылку, чтобы использовать тот же календарь на других устройствах.

### 3. Установка как PWA (опционально)

- **Android:** Открой в Chrome → "Добавить на главный экран"
- **iOS:** Открой в Safari → "Поделиться" → "На экран «Домой»"
- **Компьютер:** Иконка установки в адресной строке

## 🔧 Настройка Firebase

### Шаг 1: Создание проекта Firebase

1. Перейди на [Firebase Console](https://console.firebase.google.com/)
2. Нажми "Добавить проект"
3. Введи название проекта
4. Создай проект

### Шаг 2: Настройка Firestore Database

1. В меню слева выбери **"Firestore Database"**
2. Нажми **"Создать базу данных"**
3. Выбери режим **"Начать в тестовом режиме"**

### Шаг 3: Получение конфигурации

1. Перейди в **⚙️ Settings** → **Project settings**
2. Прокрути вниз до **"Your apps"**
3. Нажми на иконку **Web** (`</>`)
4. Скопируй объект `firebaseConfig`

### Шаг 4: Вставка конфигурации

Открой `firebase-config.js` и замени значения в объекте `firebaseConfig` на свои.

## 🎨 Особенности

- **Осенняя цветовая схема** - теплые бежевые и оранжевые тона
- **Адаптивный дизайн** - работает на телефонах и компьютерах
- **Темная/светлая тема** - автоматическая адаптация
- **Календарь FullCalendar** - визуализация задач

## 📝 Использование

1. **Добавь ритуал/задачу:** Нажми кнопку "Добавить" в нужном разделе
2. **Включи напоминание:** Поставь галочку "Включить напоминание" и укажи время
3. **Отметь выполнение:** Кликни на задачу в списке или в календаре
4. **Поделись календарем:** Используй ссылку с `calendarId` для доступа с других устройств

## 🔒 Безопасность

- Данные хранятся в Firebase Firestore
- Каждый календарь имеет уникальный ID
- Доступ только по ссылке с `calendarId`
- Локальный кэш для офлайн-работы
